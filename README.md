# 酒店运营助手

面向零基础同事的酒店运营技能。版本 v1.1。

从 [技能入口](hotel-operations-assistant/SKILL.md) 开始，下载 [Word使用教程](hotel-operations-assistant/assets/hotel-assistant-user-guide.docx)，或阅读 [文字教程](hotel-operations-assistant/assets/user-guide.md)。

直接说：**你能帮我做什么来着？详细讲讲，并给我Word使用教程。**

支持筹开调研、经营报表、收益渠道、财务跟进、客房交接与管理文稿。业务按需求确认、方案选择、确认后执行推进。

将 hotel-operations-assistant 文件夹复制到支持 SKILL.md 的平台技能目录；具体加载方式依平台而定。计算脚本使用Python标准库；OCR和办公输出需配置对应依赖。教程默认可直接下载，重新生成需python-docx。

不附公司资料、个人记忆、凭证或酒店系统权限。未连接PMS；文件生成不等于业务验收。Word已结构检查，本机缺少LibreOffice，尚未完成页面渲染验证。

第三方来源与许可见技能目录 THIRD_PARTY_NOTICES.md。未指定本项目新增代码的开源许可；公开可阅读不等于授予任意再许可权。
