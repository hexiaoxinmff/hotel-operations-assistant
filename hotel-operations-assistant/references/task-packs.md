# 按岗位完成任务：六项完整工作包
只对当前任务加载对应包。所有包沿用需求确认→方案选择→正式执行，不让同事先选岗位或填代码。模板和虚构样例在../assets/task-packs，原始资料不放进通用包。

| 大白话需求 | 内部角色/工作包 | 加载 |
| --- | --- | --- |
| 看看同行房价，我们怎么定价 | 收益/调研：报价可比性 | [价格](task-packs/prices.md) |
| 把差评整理成能改的问题 | 服务质量：评价证据 | [评价](task-packs/reviews.md) |
| 几份报告对不上，帮我核实 | 总经理：主张冲突 | [报告](task-packs/conflicts.md) |
| 开业前还差什么 | 筹开统筹：缺口与依赖 | [筹开](task-packs/opening.md) |
| 今天生意怎么样，明天怎么做 | 经营负责人：日报诊断 | [日报](task-packs/daily.md) |
| 哪些房清好了、维修还没交接 | 客房管家：交接与验收 | [交接](task-packs/handover.md) |

六包都要交付：结论→来源与期间→可复核表→排除及缺失→建议行动（责任岗位/时限标建议）→待验收。例子只是虚构练习，不能混入酒店主档。深层收益/财务任务读[专业测算](professional-analysis.md)，遇到接口/数据缺口读[适配合同](read-only-adapters.md)。
