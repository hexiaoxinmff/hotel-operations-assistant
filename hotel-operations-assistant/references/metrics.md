# 经营指标与收益管理

## 先对齐数据

确认营业日/自然日、酒店与部门范围、币种、含税/未税、人民币元/万元、房晚/订单/间数、房费确认规则，以及免费房、自用房、维修停用房和取消/未到店口径。内部管理的可售房晚按已确认的逐日口径计算；外部对标/报告必须按所用机构的对应产品指南确定供应、停用和免费房规则，不能仅按酒店习惯。STR历史报告对短期装修停用房有专门规定，不等同于内部可售库存。两种口径分别标注，不静默切换。缺值不按零；重复记录先列疑点，不擅删；负数先核查退款或冲销。

## 常用公式

| 指标 | 公式及限制 |
|---|---|
| 入住率 OCC | 已售房晚÷可售房晚；披露免费房和自用房是否计入 |
| 平均房价 ADR | 对应客房收入÷已售房晚；客房收入与房晚范围一致 |
| RevPAR | 对应客房收入÷可售房晚；同口径时等于ADR×OCC小数值 |
| TRevPAR | 总营业收入÷可售房晚；明确总收入范围 |
| GOP / GOPPAR | 按确认的经营会计范围计算GOP；GOP÷可售房晚；不得直接用净利润替代 |
| 渠道获客成本 | 明确计入佣金、活动补贴、支付费等哪些项目；与渠道收入匹配 |
| 餐饮客单价 | 餐饮收入÷就餐人次；不可混用桌数 |
| 食材成本率 | 同期耗用食材成本÷对应餐饮收入；采购额不能直接替代耗用成本 |
| 预算差异 | 实际−预算；差异率=(实际−预算)÷预算，预算为零时标不适用 |
| 同比/环比 | (本期−可比期)÷可比期；可比期为零时不算增长率 |

分母为零时标“不适用”，分母缺失标“待补”；不产出无穷大。汇总ADR和入住率用收入/房晚合计重算，不平均每日百分比。同比检查营业天数、节假日错位、停业及新开房量变化。入住率变化用百分点表达，例如70%到75%为+5个百分点。

验证算例（纯虚构）：100间每日可售房，30天共3000可售房晚；售出2100房晚，客房收入630000元。OCC=70%，ADR=300元，RevPAR=210元。另一个期间可售房晚为0时，OCC和RevPAR不适用。

## 收益和渠道

结合在手预订、预订增量（pickup）、取消、提前期、房型、客源/渠道和节假日分析。比较在手预订须对齐入住日期和距入住天数，不能拿未来在手与历史最终实绩直接断言增长。

房价建议给适用日期/房型、现价、建议区间、依据、佣金和取消条件、可售库存及复核触发条件；成本底线和品牌/合同限制未知时列待核。不要只因入住率低就全面降价。超售建议须有可执行的接待/安置规则及酒店授权，默认不自动超售。

经营报告分开写实绩、预算和预测；提出异常的可能原因及验证材料，相关性不写成因果。报表没有成本数据时不声称利润提高或核算真实GOP。

公开依据与适用边界见[web-validation.md](web-validation.md)，尤其注意外部对标与内部管理口径区别。
