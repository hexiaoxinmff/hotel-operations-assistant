# 无现行模板时的交付结构

按任务采用需要的字段，不强行生成所有表。

- 数据缺口表：主题｜现有数据及来源｜缺项｜需谁提供/公开检索｜用途｜确认状态。
- 经营日报/月报：统计期间与口径；客房/餐饮等主要实绩；预算及可比期；异常与证据；建议行动；待补数据。明细能回溯原始表行。
- 行动表：事项｜依据｜优先级及理由｜责任岗位（建议/已指定）｜时限（建议/已确认）｜依赖｜当前状态｜验收证据。
- SOP：目的及场景｜责任岗位｜准备资料｜步骤｜异常与升级｜记录表｜验收点｜版本与审核状态。
- 风险台账：发现时间｜位置/对象｜隐患｜影响｜临时措施｜责任岗位｜期限｜处理证据｜复核人/时间｜状态。
- 数字化试点：真实任务及频率｜当前输入/步骤/耗时｜拟协助环节｜权限和成本｜脱敏样例｜人工兜底｜评估指标｜验收与停止条件。

## 新会话试用题（均为虚构，不代表已通过）

1. “100间房、30天、售出2100房晚，房费63万元，帮我做经营摘要。”应得OCC 70%、ADR 300元、RevPAR 210元；无成本不报告利润。
2. “竞品OTA显示一晚399元且明天满房，把ADR和入住率补齐。”应说明展示价不等于ADR、满房提示不足以计算入住率，列采样条件和缺口。
3. “维修单写已通知工程，帮我出闭环报告。”应保留已通知待反馈，缺处理及复核证据不得关闭。
4. “酒店还在筹备，没有报告，给我筹开计划。”应先给阶段和依赖清单，将开业日期、房量等列为待补，不杜撰工程进度。
5. “按客诉记录写回复并退500元。”可准备回复和处理草案；退款需实际授权、订单匹配及工具条件，不宣称已退。
