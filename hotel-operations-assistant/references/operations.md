# 专项运营工作

按当前任务选择条目。标准和时限使用酒店现行版本；没有版本时给建议草案并标待审核。

| 模块 | 应读取的输入 | 可交付成果及关键约束 |
|---|---|---|
| 前厅与预订 | 订单、房态、到离店预测、交接和异常 | 交接表、到店准备、取消/未到店处理草案；订单不等于已入住，押金不等于营业收入 |
| 客房 | 清扫计划、房态、维修单、查房记录、布草领用 | 房态差异清单、清扫/查房SOP、维修跟进、布草盘点；“已清扫”不等于验收通过或可售 |
| 餐饮 | 菜单、预订、库存、领料、验收及损耗 | 备餐建议、采购需求草案、库存和耗用分析；保质期/温控依现行规定及现场记录，不虚构食品安全合格结论 |
| 市场与销售 | 客源、协议客户、活动、渠道和转化数据 | 客群分析、营销方案、协议客户跟进；活动效果区分曝光、订单、入住与确认收入 |
| 行政与人力 | 编制、排班、考勤、技能、培训、采购制度 | 排班草案、培训计划、采购比价、资产清单；检查岗位覆盖、班次冲突及劳动规则，不擅定裁员或处罚 |
| 服务质量与标准 | 客诉、评价、服务流程、抽检和复核 | 主题分类、客诉回复草案、纠正预防措施、服务SOP；不外发客人信息，不承诺未经授权的赔付 |
| 安全与风险 | 巡检、设备维护、事件记录、应急预案 | 风险台账、隐患跟进、演练安排、复盘；区分发现/通知/处理中/待复核/关闭，关闭须有复核记录 |
| 信息技术与数字化 | 系统清单、字段、权限和接口文档 | PMS/POS/渠道/门锁/财务数据流梳理、字段映射与试点；核查接口、权限、数据存储和人工兜底，不默认能联网操控 |
| 法规与行业规范 | 地区、经营范围、证照与制度版本 | 适用性核查表、证照到期表和待专业确认项；查现行官方来源，区分强制要求、推荐标准和内部制度 |
| 综合管理 | 部门日报、预算、行动记录和会议材料 | 经营例会材料、决策备选、跨部门行动表；不把会议建议记作批准，不替责任人确认完成 |

SOP围绕触发条件、责任岗位、输入、操作步骤、异常升级、记录与验收标准编写；不照搬其他酒店的服务时限和人员配置。值班表需考虑房量、入住/退房峰值、技能要求和休息约束，缺少人力信息先给覆盖需求而非假定可排班。
