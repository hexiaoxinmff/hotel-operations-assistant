# 夜审与经营异常核查

这是资料核查辅助，不是关账、自动补记或审计意见。先确认营业日、酒店/币种、税费口径、已关账区间及文件覆盖。只处理用户选定方案和已授权资料；每个检查项保留“疑点/无法判断/已核对未见该异常/不适用”，后两项仅在资料充分且确实检查时使用。

| 检查 | 所需证据 | 异常或限制及建议动作 |
|---|---|---|
| 重复 | 系统交易ID、酒店范围、原表行、冲销关联 | 相同ID或同日汇总多条先列疑似重复，不按相同金额/姓名直接删 |
| 未入账房费 | 实际入住区间、房费计划、账务明细、免费及调整批准 | 先区分免费、延迟入账、跨日及真漏记；无计划费用无法断定漏记 |
| 未到店候选 | 在手预订、实际到店记录、取消和改期信息 | 只列待前台核实候选，不自动扣款、取消或释放房量 |
| 房态冲突 | 同时点PMS、查房、维修、渠道库存 | 导出时间差先排除，现场有权限岗位复核，不自动改库存 |
| 余额与支付 | 期初、应收/收费、付款、调整及期末，交易范围 | 用酒店确认的正负号和账务口径对账；押金不直接算收入；镜像公司账不重复合计 |
| 撤销/减免/退款 | 原交易、原因、审批、到账/退款记录 | 申请、批准、系统操作、到账分开；有退款申请不等于已退 |
| 税费 | 房价含税规则、有效税率、豁免及账务 | 不预设统一税率；缺适用依据标无法判断，不能仅因零税额认定异常 |
| 收银差异 | 班次开关账、备用金、实际盘点、支付渠道 | 现金、刷卡及渠道结算分开，未到账不一定漏收；不删除差额凑平 |
| 指标异常 | 同期同口径收入及房晚、可比历史 | 检查零分母、售房晚超可售、负收入、重复日记录；阈值无确认不自行定红线 |

输出：检查范围与覆盖率说明｜异常ID｜检查项｜原文件/表/行｜事实｜可能原因｜金额或业务影响（有依据才算）｜需补资料｜建议责任岗位｜状态及复核证据。

查不出与没资料查分开。汇总“8项中核查3项、5项缺资料”不能写“夜审通过”。高风险异常先提示现场核对，助手不擅自改账。
